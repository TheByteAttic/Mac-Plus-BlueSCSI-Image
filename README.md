# Ready-to-Use Macintosh Plus BlueSCSI Disk Image
Complete BlueSCSI disk image, including many games, for a Macintosh Plus 1MB.
<p></p>
<img width="1067" height="800" alt="IMG_1848" src="https://github.com/user-attachments/assets/b0632138-604e-40f7-95fc-b632687100e4" />
<p></p>
<p>Just download the .zip archive above, extract all files from it, and then copy all extracted files to the root directory of an exFAT-formatted SD card. Insert the SD card into the BlueSCSI and boot your Macintosh Plus from it. On the desktop, double-click "6.0.8 2GB (D)". You will then find a folder called "Games," with many games ready to be launched. Have fun!
