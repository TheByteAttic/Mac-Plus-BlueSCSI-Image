# Ready-to-Use Macintosh Plus BlueSCSI Disk Image
Complete BlueSCSI disk image, including many games, for a Macintosh Plus 1MB.
<p></p>
<img width="600" height="600" alt="IMG_1864" src="https://github.com/user-attachments/assets/2870190b-1168-43c1-9b1b-44d222dc23fe" />
<p></p>
<p>Just download the .zip archive above, extract all files from it, and then copy all extracted files to the root directory of an exFAT-formatted SD card. Insert the SD card into the BlueSCSI and boot your Macintosh Plus from it. On the desktop, double-click "System 608". You will then find a folder called "Games," with many games ready to be launched. Have fun!
